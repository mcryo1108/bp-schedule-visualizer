# Flooding / Serial BP Visualizer

元の `BP Decoder Visualizer` の符号、エラー生成、表示、パラメータを保ち、BPの更新方式を切り替えられるようにした版です。

表面符号に加えて、data qubitをハニカム格子の頂点、3色の面をparity checkとする三角形6.6.6カラー符号を選択できます。カラー符号の距離は `d=3,5,7` です。

## 更新方式

- フロッディング: 全チェックノードのメッセージを同時に更新し、その後に全変数ノードのメッセージを同時に更新します。`BP step` は半反復ずつ進みます。
- シリアル: 変数ノードを1個ずつ更新します。昇順、降順、スイープ開始前に生成するランダム順序から選べます。実際の更新順序は操作パネルに全件表示されます。先に処理した変数ノードの新しい `v→c` メッセージは、同じスイープ内の後続変数ノードが使います。`BP step` は変数ノード1個分ずつ進みます。

FloodingとSerialの自動実行速度は、1ステップを20 msごとに更新する標準モードと、1ステップを1 msごとに更新する最速モードから選べます。

更新方式を切り替えると、現在のエラーパターンを保持したままBPメッセージだけを初期化します。そのため、同じ入力に対する2方式の収束経路を比較できます。

全符号モードで変数ノードをクリックすると、そのノードの真のエラーを `0↔1` で反転できます。シンドロームは直ちに再計算され、BPメッセージは新しいエラーパターンに対して初期化されます。変数ノード以外の図領域をクリックすると、従来どおりBPを1ステップ進めます。

図領域の右上にある `図とLLRをコピー` を押すと、全符号モードでタナーグラフとLLR履歴を1枚のPNG画像としてクリップボードへコピーできます。そのまま資料やチャットへ貼り付けられます。
